# Praktikum 1 - Flutter Refresh

## Tujuan
Praktikum ini bertujuan untuk memahami dasar pengembangan aplikasi mobile menggunakan Flutter, termasuk struktur project, widget dasar, dan menjalankan aplikasi pada perangkat Android.

## Fitur Utama
- Menampilkan profil mahasiswa.
- Menampilkan nama mahasiswa.
- Menampilkan NIM.
- Menampilkan informasi mata kuliah.
- Menampilkan semester.
- Menggunakan beberapa widget dasar Flutter seperti `Scaffold`, `AppBar`, `Center`, `Column`, `Icon`, `Text`, `SizedBox`, dan `Container`.

Stack Teknologi
- Flutter
- Dart
- Android

Cara Menjalankan
1. Pastikan Flutter sudah terpasang dan dapat digunakan.
2. Buka folder project melalui terminal.
3. Jalankan perintah:
   ```bash
   flutter pub get
   flutter run

Hasil yang Dicapai
Aplikasi berhasil dibuat dan dijalankan pada perangkat Android. Aplikasi menampilkan halaman profil mahasiswa dengan informasi nama, NIM, mata kuliah, dan semester.
