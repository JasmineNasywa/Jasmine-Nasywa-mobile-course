##warm-up layout sederhana##

1. Import Flutter
import 'package:flutter/material.dart';
import

Artinya: ambil / masukkan sesuatu dari library lain supaya bisa dipakai di file ini.

Ibaratnya:

“Flutter, pinjem alat-alat UI lu dong.”

'package:flutter/material.dart'

Ini adalah lokasi library Flutter yang mau kita gunakan.

package: → menunjukkan kita mengambil package
flutter → package Flutter
material → kumpulan komponen Material Design
dart → file/library Dart

material.dart menyediakan banyak hal seperti:

MaterialApp
Scaffold
Container
Text
Row
Column
Icon
Colors
CircleAvatar

Jadi tanpa import ini, nama-nama tersebut tidak akan dikenali.

2. Fungsi main()
void main() => runApp(const ProfileApp());

Ini bagian titik awal aplikasi.

void

Menunjukkan bahwa fungsi main() tidak mengembalikan nilai.

Contoh:

void makan() {
}

Fungsinya melakukan sesuatu, tapi tidak mengembalikan hasil.

main()

main adalah fungsi utama Dart.

Program mulai dieksekusi dari sini.

Jadi:

main()
 ↓
runApp()
 ↓
ProfileApp
 ↓
UI
=>

Ini disebut arrow syntax.

void main() => runApp(...);

Kurang lebih sama dengan:

void main() {
  runApp(...);
}

Karena cuma ada satu expression, Dart memperbolehkan bentuk pendek.

runApp(...)

Fungsi Flutter untuk menjalankan widget sebagai root aplikasi.

runApp(const ProfileApp());

Artinya:

“Flutter, jalankan ProfileApp sebagai aplikasi utama.”

const ProfileApp()

Membuat object/widget ProfileApp.

const berarti object tersebut dibuat sebagai konstanta, selama isinya bisa ditentukan secara konstan.

Nggak perlu terlalu dipusingkan dulu. Yang penting untuk sekarang:

const = widget/object yang nilainya tidak perlu dibuat ulang karena sifatnya konstan.

3. Class aplikasi
class ProfileApp extends StatelessWidget {

Nah ini penting.

class

class digunakan untuk membuat blueprint/template sebuah object.

Misalnya:

class Mobil {
}

Kita membuat blueprint bernama Mobil.

Di sini:

class ProfileApp

kita membuat blueprint widget bernama ProfileApp.

ProfileApp

Nama class kita.

Namanya bebas sebenarnya:

class ProfileApp
class MyApp
class AplikasiSaya

Tapi biasanya pakai nama yang menjelaskan fungsinya.

extends

Artinya:

ProfileApp mewarisi kemampuan dari class lain.

ProfileApp extends StatelessWidget

Jadi ProfileApp adalah turunan dari StatelessWidget.

StatelessWidget

Widget yang tidak memiliki state yang berubah-ubah sendiri.

Misalnya tampilan:

Nama: Venn
NIM: 12345
Kelas: TI-4

Kalau datanya tidak berubah selama widget berjalan, StatelessWidget cocok.

Nanti ada juga:

StatefulWidget

untuk widget yang punya state yang bisa berubah.

4. Constructor
const ProfileApp({super.key});

Ini adalah constructor dari ProfileApp.

Constructor dipanggil ketika kita melakukan:

ProfileApp()
const

Sama seperti tadi, constructor-nya bisa dibuat secara konstan.

{ ... }

Kurung kurawal di sini menunjukkan named parameter.

super.key

Ini sedikit lebih teknis.

key adalah identitas yang bisa digunakan Flutter untuk mengenali widget tertentu dalam widget tree.

super berarti parameter tersebut diteruskan ke constructor parent class, yaitu:

StatelessWidget

Jadi:

{super.key}

kurang lebih konsepnya:

“Kalau ada key, teruskan ke StatelessWidget.”

Untuk tugas dasar Flutter, kamu biasanya cukup hafal pola:

const NamaWidget({super.key});

Ini boilerplate yang sering banget muncul.

5. Method build
@override
Widget build(BuildContext context) {

Ini salah satu bagian PALING penting di Flutter.

@override

Artinya:

“Saya sedang membuat ulang method yang sudah dimiliki parent class.”

StatelessWidget punya method build(), lalu kita override.

Widget

Ini adalah tipe return.

Artinya method build() harus mengembalikan sebuah Widget.

Contohnya:

Widget build(...) {
  return Text("Halo");
}
build

Nama method yang digunakan Flutter untuk membangun UI widget.

(BuildContext context)

Parameter yang diberikan Flutter kepada build().

BuildContext

Menyimpan informasi mengenai posisi widget tersebut di widget tree.

Misalnya nanti digunakan untuk:

Theme.of(context)
Navigator.of(context)
MediaQuery.of(context)

Untuk kode kamu sekarang, context belum digunakan secara langsung.

context

Nama variable untuk objek BuildContext.

Namanya sebenarnya bisa diganti:

BuildContext ayam

tapi jangan. 😭

Gunakan convention:

BuildContext context

Cara membaca Flutter yang paling enak: jangan baca sebagai kalimat dari kiri ke kanan. Baca sebagai pohon widget.

Scaffold punya body → body punya Center → Center punya ProfileCard → ProfileCard punya Container → Container punya Column → Column punya Row, SizedBox, Row, Row.

Begitu pola parent → child ini sudah masuk otak, kode Flutter yang tadinya kelihatan kayak kurungan matematika kesurupan bakal jauh lebih masuk akal. 😭✋
