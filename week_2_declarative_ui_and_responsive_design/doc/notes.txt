2. Fungsi main()
void main() => runApp(const ProfileApp());

Ini bagian titik awal aplikasi.

void

Menunjukkan bahwa fungsi main() tidak mengembalikan nilai.

Contoh:

void makan() {
}

Fungsinya melakukan sesuatu, tapi tidak mengembalikan hasil.

main()

main adalah fungsi utama Dart.

Program mulai dieksekusi dari sini.

Jadi:

 ↓

=>

Ini disebut arrow syntax.

void main() => runApp(...);

Kurang lebih sama dengan:

void main() {
  runApp(...);
}

Karena cuma ada satu expression, Dart memperbolehkan bentuk pendek.

runApp(...)

Fungsi Flutter untuk menjalankan widget sebagai root aplikasi.

runApp(const ProfileApp());

Artinya:

“Flutter, jalankan ProfileApp sebagai aplikasi utama.”

const ProfileApp()

Membuat object/widget ProfileApp.

const berarti object tersebut dibuat sebagai konstanta, selama isinya bisa ditentukan secara konstan.

Nggak perlu terlalu dipusingkan dulu. Yang penting untuk sekarang:

const = widget/object yang nilainya tidak perlu dibuat ulang karena sifatnya konstan.

Ini sedikit lebih teknis.

## `constraints.maxWidth`

`constraints` berasal dari:

```dart

```

`maxWidth` = lebar maksimum yang tersedia.

Misalnya layar:

```text
lebar = 800
```

maka:

```dart

```

bisa bernilai sekitar 800.

# 21. Operator `>=`

```dart
constraints.maxWidth >= 700
```

Artinya:

> Apakah `maxWidth` lebih besar atau sama dengan 700?

Contoh:

```text
800 >= 700 → true
500 >= 700 → false
700 >= 700 → true
```

---

# 22. Ternary operator `? :`

Ini:

```dart
condition ? nilaiJikaTrue : nilaiJikaFalse
```

Jadi:

```dart
constraints.maxWidth >= 700 ? 2 : 1
```

dibaca:

> Kalau lebar >= 700, pakai 2 kolom. Kalau tidak, pakai 1 kolom.

Setara dengan:

```dart
int columns;

if (constraints.maxWidth >= 700) {
  columns = 2;
} else {
  columns = 1;
}
```

Jadi kode pendeknya:

```text
lebar >= 700?
   │
   ├── YES → 2 kolom
   │
   └── NO  → 1 kolom
```

**Inilah responsive layout-nya.**

Dan **3 konsep baru terbesar** dari kode ini sebenarnya cuma:

### ① Responsive

```dart
final columns = constraints.maxWidth >= 700 ? 2 : 1;
```

> Layar kecil → 1 kolom
> Layar besar → 2 kolom

### ② Theme

```dart
theme: ThemeData(...)
darkTheme: ThemeData(...)
themeMode: ThemeMode.system
```

> Aplikasi punya light + dark theme dan mengikuti sistem.

### ③ Custom widget dengan parameter

```dart
DashboardCard(
  title: 'Assignments',
  value: '8',
)
```

yang masuk ke:

```dart
const DashboardCard({
  required this.title,
  required this.value,
});
```

Lalu disimpan:

```dart
final String title;
final String value;
```

Jadi data bisa **dikirim dari parent ke child**.
