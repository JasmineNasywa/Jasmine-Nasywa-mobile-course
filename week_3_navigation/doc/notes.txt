

Intinya kode ini membuat **navigasi antar halaman menggunakan URL/path**, dibantu package `go_router`.

---

# 0. `flutter pub add go_router`

```bash
flutter pub add go_router
```

Kita bedah:

* `flutter` → perintah untuk menjalankan tools Flutter.
* `pub` → pengelola package/dependency Dart.
* `add` → menambahkan dependency baru ke project.
* `go_router` → nama package yang mau ditambahkan.

Jadi artinya:

> **"Flutter, tolong tambahkan package bernama `go_router` ke project ini."**

Nanti otomatis masuk ke `pubspec.yaml`.

# 1. Struktur folder

```text
lib/
```

### `lib/`

Folder utama tempat kode Dart aplikasi Flutter biasanya berada.

```dart

```

berada.

Folder untuk menyimpan file-file halaman.

Ini **bukan aturan wajib Flutter**, cuma cara merapikan project.

File untuk halaman Detail.

Jadi:

```text
main.dart
   ↓

```

# 4. Ini bagian paling penting: `_router`

### `_router`

Ini **nama variabel**.

Namanya sebenarnya bisa saja:

Tapi programmer memberi nama `_router` karena router ini hanya dipakai di file tersebut.

# 7. `GoRoute`

```dart
GoRoute(
```

`GoRoute` adalah **satu aturan navigasi**.

Gampangnya:

> "Kalau URL/path-nya begini, tampilkan halaman ini."

---

## Route pertama

```dart
GoRoute(
  path: '/',
  builder: (context, state) => const HomePage(),
```

### `path`

```dart
path: '/',
```

Menentukan path yang harus cocok.

Kalau aplikasi berada di:

```text
/
```

maka router akan menggunakan route ini.

---

### `builder`

```dart
builder: (context, state) => const HomePage(),
```

`builder` adalah fungsi yang menentukan:

> **"Widget apa yang harus dibuat ketika route ini dibuka?"**

Di sini jawabannya:

```dart
HomePage()
```

Jadi:

```text
path: '/'
      ↓
HomePage()
```

---

### `(context, state)`

Dua parameter yang diberikan `GoRouter` kepada builder.

#### `context`

`BuildContext`.

Memberi informasi tentang posisi widget tersebut di dalam widget tree dan memungkinkan kita mengakses berbagai fitur Flutter.

#### `state`

`GoRouterState`.

Berisi informasi mengenai route yang sedang dibuka.

Nanti `state` ini sangat berguna buat mengambil parameter URL.

# 8. `routes` di dalam `routes`

Nah ini bagian yang biasanya bikin orang:

**"HAH KOK ROUTES ADA ROUTES LAGI 😭"**

```dart
routes: [
  GoRoute(
    path: '/',
    builder: ...,
    routes: [
      GoRoute(
        path: 'detail/:id',
```

Route di dalam route adalah **child/nested route**.

Route utama:

```text
/
```

Child route:

```text
/detail/:id
```

Digabung menjadi:

```text
/detail/1
/detail/2
/detail/3
```

dan seterusnya.

---

# 9. `detail/:id`

```dart
path: 'detail/:id',
```

Ini keren sedikit.

### `detail`

Bagian path biasa.

### `:id`

Ini disebut **path parameter**.

Artinya `id` bisa berubah.

Jadi satu route ini bisa menangani:

```text
/detail/1
/detail/2
/detail/3
/detail/10
/detail/999
```

Daripada kita harus menulis:

```dart
GoRoute(path: 'detail/1')
GoRoute(path: 'detail/2')
GoRoute(path: 'detail/3')
```

yang jelas merupakan cara manusia menemukan penderitaan baru.

Dengan:

```text
detail/:id
```

kita cukup punya **satu route dinamis**.

# 10. `state.pathParameters`

```dart
state.pathParameters['id']!
```

Ini mengambil nilai `id` dari URL.

Misalnya user membuka:

```text
/detail/7
```

Maka:

```dart
state.pathParameters['id']
```

isinya:

```text
"7"
```

Karena parameter path berupa String.

---

### Kenapa `['id']`?

Karena parameter kita tadi namanya:

```text
:id
```

Jadi kita mengambil parameter dengan key:

```dart
['id']
```

---

### Terus `!` apaan?!

```dart
state.pathParameters['id']!
```

`!` disebut **null assertion operator**.

Artinya programmer mengatakan kepada Dart:

> "Saya yakin nilai ini tidak null."

Tanpa `!`:

```dart
state.pathParameters['id']
```

tipe nilainya dianggap mungkin `null`.

Dengan:

```dart
state.pathParameters['id']!
```

kita bilang:

> "Anggap ini pasti ada."

Karena route kita memang mensyaratkan:

```text
:id
```

---

# 11. `DetailPage`

```dart
DetailPage(
  id: state.pathParameters['id']!,
),
```

Kita membuat halaman Detail sambil **mengirimkan id**.

Misalnya URL:

```text
/detail/5
```

maka kira-kira:

```dart
DetailPage(id: '5')
```

Jadi alurnya:

```text
/detail/5
    ↓
ambil "5"
    ↓
state.pathParameters['id']
    ↓
DetailPage(id: '5')
```

# 🧠 Jadi keseluruhan mekanismenya begini

Misalnya kamu klik:

**Item 7**

Maka:

```text
HomePage
   │
   │ user tap Item 7
   ↓
onTap
   │
   ↓
context.go('/detail/7')
   │
   ↓
GoRouter mencari route
   │
   ↓
path: 'detail/:id'
   │
   ↓
:id = "7"
   │
   ↓
state.pathParameters['id']
   │
   ↓
DetailPage(id: "7")
   │
   ↓
┌─────────────────────────────┐
│ Detail 7                    │
├─────────────────────────────┤
│                             │
│ Anda membuka item dengan    │
│ id: 7                       │
│                             │
└─────────────────────────────┘
```

### Jadi 5 nama yang PALING penting kamu hafalin:

| Nama             | Artinya                            |
| ---------------- | ---------------------------------- |
| `GoRouter`       | Pengatur navigasi                  |
| `GoRoute`        | Aturan/alamat suatu halaman        |
| `path`           | Alamat halaman                     |
| `context.go()`   | Pergi ke alamat tertentu           |
| `pathParameters` | Mengambil nilai dari parameter URL |

Dan hubungan paling pentingnya:

```text
GoRouter
   ↓
punya banyak GoRoute
   ↓
setiap GoRoute punya path
   ↓
context.go() menuju path
   ↓
pathParameters mengambil data dari path
```

**Contoh paling gampang:**

```text
/detail/7
   ↑    ↑
 path   id
```

`detail` = nama jalur
`7` = nilai `id`
`:id` = tempat kosong yang bisa diisi nilai berbeda

Jadi sebenarnya Week 3 ini sedang ngajarin kamu **navigasi + passing data lewat URL**, bukan sekadar "cara pindah halaman". Itu sebabnya ada `:id` dan `pathParameters`. 🫵😭
